# Circuit Critters — יצורי המעגל

A playful 3D platform puzzler in a giant tabletop toy workshop: rebuild live battery circuits to animate bridges, lifts and magnetic grapples, then exploit the topology you created to traverse.

Status: design handoff; builder implementation is starting. Proposed screenshot images are visual targets, not proof of implemented gameplay.

See [BUILD_HANDOFF.md](BUILD_HANDOFF.md) and [COMMON.md](COMMON.md) for curriculum, asset workflow and acceptance criteria.

The intended stack is TypeScript with a real 3D engine, Hebrew RTL interface and a browser-playable single-player slice. Local development port: 5193.
